# Deployment and launch gates

This repository is built locally only. No Vercel project, custom domain, DNS record, Wix page, external service, or GitHub repository was changed.

The planned canonical origin is `https://industries.distilledfunding.com`; it is a configuration target, not proof that the hostname is connected. `https://distilled-industries.vercel.app` is configured as the intended preview host, not confirmed as an active deployment. Page canonicals use the planned production host while all pages remain noindex. `CANONICAL-SITEMAP.txt` is a checked-in inventory document; the served XML sitemap is empty.

Before any later public launch: verify the intended preview and custom-domain ownership, review all adapted content, check sibling destinations, assess public archive safety, confirm page-level index approval, and explicitly change the noindex/sitemap gates. Deployment, DNS, and indexing are outside this build authorization.
